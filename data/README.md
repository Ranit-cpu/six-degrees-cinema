Place these two files from Kaggle's **"TMDB 5000 Movie Dataset"** here before running `npm run seed`:

- `tmdb_5000_movies.csv`
- `tmdb_5000_credits.csv`

Download: https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata (free Kaggle account, no API key needed).

These CSVs are gitignored — don't commit them, the seed script reads them locally.
